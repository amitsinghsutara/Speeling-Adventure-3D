# Spelling Adventure 3D — Spec Kit

A fresh-project specification pack for a browser-based, third-person 3D cartoon spelling adventure featuring Fern the fox. Targets desktop browsers and Android WebView, with offline-first gameplay.

## How to use
1. Create a new repository/project for `spelling-adventure-3d`.
2. Copy this pack into the repository, preserving the paths.
3. Open the repository with Claude Code and check the Spec Kit commands supported by your installed version.
4. Review the constitution and spec; resolve open questions rather than inventing curriculum rules or claiming unverified compatibility.
5. Run your installed workflow (command names may vary), typically `/speckit.constitution`, `/speckit.specify`, `/speckit.clarify`, `/speckit.plan`, `/speckit.tasks`, `/speckit.implement`.
